# Aryan Rathod Portfolio --- Product Requirements Document

## 1. Product Goal

Build a premium personal portfolio that positions Aryan Rathod as a
Computer Engineering student, full-stack/web developer, and founder of
Optenary.

The website should communicate one core message:

> I build real products.

## 2. Target Audience

-   Potential clients
-   Recruiters
-   Developers
-   Startup founders
-   College and technology communities
-   Businesses looking for web/software development

## 3. Main Sections

1.  Floating Navbar
2.  Hero
3.  About
4.  Skills
5.  Selected Projects
6.  Journey / Experience
7.  Education
8.  Contact
9.  Footer

## 4. Navbar

Desktop: - Aryan Rathod - About - Skills - Work - Education - Contact -
Resume button - Theme switch

Requirements: - Sticky/floating - Rounded pill container - Active
section indicator - Smooth scrolling - Responsive mobile menu

## 5. Hero

Content: - Profile photo - Aryan Rathod - Full Stack Developer &
Founder - Founder --- Optenary badge - Short professional description -
GitHub, LinkedIn, Instagram, X, Email

Visual: - Centered - Large bold name - Circular photo - Large
whitespace - Minimal decoration

## 6. About

Include: - Professional introduction - Location - Education - Focus
area - Role - Optional project/technology/client statistics

## 7. Skills

Recommended groups: - Frontend Development - Backend & Database - Tools
& Platforms - AI, Automation & Integrations

## 8. Projects

Featured projects should be the strongest part of the website.

Initial candidates: - Mehta Dairy - Optenary - TPO Portal -
AutoSahayak - FixKaro

Each project: - Screenshot - Name - Category - Technology tags - Short
description - GitHub - Live Demo

## 9. Journey

Show education, development growth, Optenary, and production/client
projects as a timeline.

## 10. Education

Diploma in Computer Engineering R.C. Technical Institute, Ahmedabad
2024--2027

Only verified information should be published.

## 11. Contact

Include: - Email - Location - Social links - Name field - Email field -
Message field - Send button - Validation/loading/success/error states

## 12. Theme

Light and dark modes with smooth transitions.

## 13. Accessibility

-   Semantic HTML
-   Keyboard navigation
-   Focus states
-   Alt text
-   Accessible forms
-   Good contrast
-   Reduced-motion support

## 14. SEO

Include: - Title - Meta description - Open Graph - X/Twitter metadata -
Sitemap - Robots - Canonical URL - Favicon - Structured data where
useful

## 15. Performance

-   Optimized images
-   Responsive images
-   Lazy loading where appropriate
-   Minimal dependencies
-   Optimized fonts
-   Avoid unnecessary client-side JavaScript

## 16. Success Criteria

The portfolio is complete when: - All sections work - Responsive
behavior is polished - Theme switching works - Navigation works -
Project links work - Resume opens - Contact form works - SEO is
configured - Production build succeeds - No major console errors remain
